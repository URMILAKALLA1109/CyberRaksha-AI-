# 🛡️ CyberRaksha AI

**CyberRaksha AI** is an AI-powered cyber incident assistance system designed to help users understand what to do when they face common online cyber threats.

Users can describe their situation through **text or voice**, and the system analyzes the reported incident and provides relevant safety and reporting guidance.

## 🚨 What Problem Does It Solve?

When people experience online fraud, phishing, account hacking, UPI scams, or other cyber incidents, they may not know:

* What they should do immediately
* What information they should preserve
* Where they should report the incident
* How to contact the appropriate authorities

CyberRaksha AI provides step-by-step guidance based on the user's reported situation.

## ✨ Key Features

* 🎤 **Voice-based Incident Description**

  * Users can describe their cyber incident using voice.

* 💬 **Text-based Incident Description**

  * Users can type their problem instead of using voice.

* 🤖 **AI-powered Situation Understanding**

  * The system analyzes the user's description and identifies the type of cyber incident.

* 🛡️ **Immediate Safety Guidance**

  * Provides recommended actions that the user can take to reduce further risk.

* 📞 **1930 Assistance**

  * Provides guidance for contacting India's cyber fraud helpline **1930** when applicable.

* 🚔 **Cyber Crime Reporting Guidance**

  * Helps users understand the process of reporting the incident to the appropriate cybercrime authorities.

* 📋 **Incident Information Guidance**

  * Helps users identify important details and evidence that may be useful while reporting an incident.

## 🔍 Example Situations

CyberRaksha AI can provide guidance for situations such as:

* UPI / online payment fraud
* Phishing messages and links
* OTP-related scams
* Bank-related online fraud
* Social media account compromise
* Fake job scams
* Online shopping scams
* Suspicious websites or applications
* Other common cyber-security incidents

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/URMILAKALLA1109/CyberRaksha-AI-.git
```

Move into the project directory:

```bash
cd CyberRaksha-AI-
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Application

Run the application using the appropriate command for your project.

Example:

```bash
python app.py
```

Then open the local URL shown by the application.

## 🔐 Security

Do not store API keys, passwords, access tokens, or other secrets directly in the source code.

Use environment variables such as:

```text
.env
```

and make sure `.env` is included in `.gitignore`.

## ⚠️ Disclaimer

CyberRaksha AI provides general cyber-safety and reporting guidance based on the information provided by the user.

It does not replace official law-enforcement, banking, or cyber-security services.

For cyber fraud and emergencies, users should follow the appropriate official reporting and assistance channels.
